# 🎬 Next MCU Movie Tracker

A simple PHP application that fetches real-time data to display the next upcoming movie in the Marvel Cinematic Universe (MCU).

## 🚀 Features

- **Real-time Data:** Consumes the [When is the next MCU film](https://whenisthenextmcufilm.com/api) API.
- **Backend Logic:** Uses PHP and **cURL** to handle API requests and JSON processing.
- **Minimalist Design:** Styled with [Pico CSS](https://picocss.com/) for a modern, responsive look without heavy dependencies.

## 🛠️ Technologies Used

- **PHP 8+** (Core logic & API consumption)
- **cURL** (HTTP Requests)
- **HTML5 / CSS3**
- **Pico CSS** (Classless framework)
